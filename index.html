Clau d'accés a GitHub

Per desar canvis cal una clau personal (fine-grained token) amb permís Contents: Read and write només sobre aquest repositori.

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. Repository access: només aquest repositori
  3. Permissions → Contents: Read and write

Es guarda només en aquest navegador.
